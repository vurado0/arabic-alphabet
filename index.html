Arabic Alphabet الأبجدية

28 letters plus hamza. Arabic is read right to left. Press Name to hear the letter's name, Sound to hear it with the three short vowels (a, i, u). Rows tagged new sound have no real match in English, German or Japanese.

Mac: System Settings → Accessibility → Spoken Content → System voice → Manage Voices → Arabic. iPhone: Settings → Accessibility → Spoken Content → Voices → Arabic. Windows: Settings → Time & language → Speech → Add voices → Arabic. Android: Settings → Text-to-speech → Speech Services by Google → Install voice data → Arabic.
